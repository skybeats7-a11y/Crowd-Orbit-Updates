# Crowd Orbit Updates

Public release feed for Crowd Orbit.

This repository contains only Crowd Orbit release metadata and finished update bundles. The Android source code remains in the private `Crowd-Orbit` repository.

The installed Crowd Orbit v0.5 Android engine checks `latest.json` automatically. The initial feed advertises v0.5.0, matching the version bundled in the APK, so no remote bundle is downloaded yet.

Future UI and logic releases will be published here with a versioned ZIP and matching SHA-256 checksum.
